Real-Time EV Charging Station Availability & Demand Predictor ⚡🚗A robust, end-to-end data engineering and machine learning pipeline designed to predict electric vehicle (EV) charging station availability and demand status in real time. This project combines MongoDB for data storage, PySpark and Pandas for scalable preprocessing and feature engineering, and high-performance machine learning algorithms to reduce range anxiety and optimize station utilization.📌 Project OverviewWith the rapid acceleration of electric vehicle adoption, drivers and grid operators face two primary challenges:Range Anxiety: Drivers need accurate, real-time forecasts regarding charger availability.Grid Congestion: Utility providers require demand forecasting to prevent localized power overloads.This project addresses both challenges by engineering a scalable pipeline that ingests raw telemetry, cleans and normalizes features in a distributed environment using PySpark, trains high-accuracy ML models (Random Forest & Logistic Regression), and performs live inference on incoming telemetry data.🏗️ Architecture & Pipeline[ MongoDB ] ➡️ [ Pandas Cleaning ] ➡️ [ PySpark Feature Pipeline ]

Data Ingestion: Ingests telemetry logs, charger status, and usage data into MongoDB.Data Processing: Cleans and formats raw data using Pandas.Feature Engineering: Leverages PySpark ML for One-Hot Encoding (OneHotEncoder) and feature scaling (StandardScaler).Machine Learning: Trains classification models (Random Forest with 300 estimators, Logistic Regression).Evaluation: Evaluates performance via Accuracy, Precision, Recall, Macro F1-score, and Confusion Matrices.Live Inference: Scores real-time incoming station metrics to predict current availability and demand.🛠️ Tech Stack & PrerequisitesTechnologies UsedLanguage: Python 3.15+Data Storage: MongoDB / PyMongoDistributed Computing & ML: Apache Spark (PySpark 3.x)Data Preprocessing & Analysis: Pandas, NumPyVisualization: Matplotlib, SeabornEnvironment: PowerShell / Windows / LinuxPython Packages Requiredpip install numpy pandas scikit-learn matplotlib seaborn pymongo pyspark
